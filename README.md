# Incidence of Multimorbidity and Its Related Factors Prevalent Among Ageing Population in India

## Project Overview

This research project investigates multimorbidity among India's ageing population using Longitudinal Ageing Study in India (LASI) Wave-1 data.

## Dataset

- Source: LASI Wave-1 (2017–18)
- Conducted by: International Institute for Population Sciences (IIPS)
- Population: Adults aged 45+ years

## Objectives

- Study prevalence of multimorbidity
- Identify socio-economic determinants
- Develop a Multimorbidity Index (MMI)
- Generate insights for public health research

## Statistical Techniques

- Descriptive Statistics
- Logistic Regression
- Chi-Square Test
- Odds Ratio Analysis
- Factor Analysis
- Tetrachoric Correlation
